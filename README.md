Java-OOP-and-DataStructures Repository

Welcome to my Java Object-Oriented Programming and Data Structures repository.

This collection includes all my Java programs, exercises, and mini-projects organized by topic and category — covering fundamental and intermediate concepts in object-oriented design and data structures.

This repository contains folders organized by category, each focusing on a different area of Java programming: object-oriented fundamentals, data structures, standalone projects, and exam practice.
